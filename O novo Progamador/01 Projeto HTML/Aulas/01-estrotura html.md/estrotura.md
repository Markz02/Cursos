# Estrutura Básica do HTML

HTML (HyperText Markup Language) é a linguagem utilizada para criar páginas web. Ele estrutura o conteúdo da página através de elementos e tags. Aqui está um exemplo básico de como funciona a estrutura de um documento HTML:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Minha Página Web</title>
  </head>
  <body>
    <h1>Bem-vindo à Minha Página</h1>
    <p>Este é um parágrafo de texto.</p>
  </body>
</html>

Vamos explicar cada parte:

<!DOCTYPE html>: Declara o tipo de documento como HTML5.

<html>: Elemento raiz que contém todo o conteúdo da página.

<head>: Contém metadados sobre o documento, como o título da página (<title>), links para arquivos de estilo e outras informações.

<body>: Contém o conteúdo visível da página, como títulos (<h1>), parágrafos (<p>), imagens, links, etc.

Os elementos HTML são definidos por tags, que normalmente vêm em pares: uma tag de abertura (<tag>) e uma tag de fechamento (</tag>). O conteúdo fica entre essas tags.
