# Tags HTML Essenciais

- `<html>`: Define o início do documento HTML.
- `<head>`: Contém meta-informações sobre o documento, como o título e links para folhas de estilo.
- `<title>`: Define o título do documento, que aparece na barra de título do navegador.
- `<body>`: Contém o conteúdo visível do documento, como texto, imagens e outros elementos.
- `<h1> a <h6>`: Tags de cabeçalho, usadas para definir títulos de diferentes níveis, sendo `<h1>` o mais importante e `<h6>` o menos importante.
- `<p>`: Define um parágrafo de texto.
- `<a>`: Cria um link para outro recurso ou página.
- `<img>`: Insere uma imagem no documento.
- `<ul>`: Define uma lista não ordenada (com marcadores).
- `<ol>`: Define uma lista ordenada (numerada).
- `<li>`: Define um item de uma lista.
- `<div>`: Define uma divisão ou seção no documento, usada para agrupar blocos de conteúdo.
- `<span>`: Define uma seção em linha (dentro de um parágrafo), usada para aplicar estilos específicos a partes do texto.
- `<table>`: Cria uma tabela.
- `<tr>`: Define uma linha em uma tabela.
- `<td>`: Define uma célula em uma linha de tabela.
