Tags HTML

Aqui estão algumas das tags HTML mais comuns e suas funções:

- `<!DOCTYPE html>`: Declara o tipo de documento como HTML5.
- `<html>`: Elemento raiz que contém todo o conteúdo da página.
- `<head>`: Contém metadados sobre o documento.
- `<title>`: Define o título da página.
- `<meta>`: Fornece metadados adicionais sobre o documento.
- `<link>`: Usado para vincular a outros recursos, como arquivos de CSS.
- `<script>`: Usado para inserir scripts de JavaScript.
- `<style>`: Contém estilos CSS internos.
- `<body>`: Contém o conteúdo visível da página.
- `<h1>` a `<h6>`: Títulos e subtítulos de diferentes níveis.
- `<p>`: Define um parágrafo.
- `<a>`: Define um link.
- `<img>`: Insere uma imagem.
- `<div>`: Define uma divisão ou seção na página.
- `<span>`: Define uma parte de texto em um documento.
- `<ul>`: Cria uma lista não ordenada.
- `<ol>`: Cria uma lista ordenada.
- `<li>`: Define um item de lista.
- `<table>`: Cria uma tabela.
- `<tr>`: Define uma linha de tabela.
- `<th>`: Define uma célula de cabeçalho de tabela.
- `<td>`: Define uma célula de tabela.
- `<form>`: Cria um formulário HTML.efine um campo de entrada dentro de um formulário.
- `<button>`: Cria um botão clicável.
