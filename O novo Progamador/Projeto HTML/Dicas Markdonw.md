### Elementos Básicos de Markdown

1. **Cabeçalhos**:
   - Para criar cabeçalhos, use o símbolo `#` seguido de um espaço, onde o número de `#` determina o nível do cabeçalho.
   - Exemplo:
     ```markdown
     # Cabeçalho Nível 1
     ## Cabeçalho Nível 2
     ### Cabeçalho Nível 3
     ```

2. **Negrito e Itálico**:
   - Para negrito, use dois asteriscos `**` ou dois underscores `__` em volta do texto.
   - Para itálico, use um asterisco `*` ou um underscore `_` em volta do texto.
   - Exemplo:
     ```markdown
     **Texto em negrito**
     *Texto em itálico*
     ```

3. **Listas**:
   - Para listas não ordenadas, use o símbolo `-` ou `*`.
   - Para listas ordenadas, use números seguidos por um ponto `1.`, `2.`, etc.
   - Exemplo:
     ```markdown
     - Item 1
     - Item 2
       - Subitem 2.1
       - Subitem 2.2
     
     1. Primeiro item
     2. Segundo item
     ```

4. **Links**:
   - Para criar links, use colchetes `[]` para o texto do link e parênteses `()` para a URL.
   - Exemplo:
     ```markdown
     [Microsoft](https://www.microsoft.com)
     ```

5. **Imagens**:
   - Para adicionar imagens, use o símbolo `!` seguido por colchetes `[]` para o texto alternativo e parênteses `()` para a URL da imagem.
   - Exemplo:
     ```markdown
     ![Logo do Markdown](https://markdown-here.com/img/icon256.png)
     ```

6. **Código**:
   - Para blocos de código inline, use crases `` ` `` em volta do texto.
   - Para blocos de código maiores, use três crases ``` ``` ``` antes e depois do código.
   - Exemplo:
     ```markdown
     `código inline`
     
     ```
     bloco de código
     ```
     ```

    

7. **Citações**:
   - Para adicionar uma citação, use o símbolo `>` seguido de um espaço.
   - Exemplo:
     ```markdown
     > Esta é uma citação.
     ```
